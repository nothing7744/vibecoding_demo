# reach · NeurIPS 2026 参会人触达系统

链路：arXiv 真实数据 → 姓名归一去重 → 个性化消息渲染 → dry-run 投递 → 唯一链接点击追踪 → **对方回应** → 漏斗看板。

## 两个入口

| 文件 | 用途 | 打开方式 |
|---|---|---|
| **`reach.html`** | **单文件版（对外分发用这个）** | 直接发给任何人，双击打开即可，无需 Python、无需联网、零依赖 |
| `reach.py` | 服务端版（真·实时抓取 / 真·SQLite 追踪） | `python reach.py`，本地 8777 端口 |

## 单文件版说明（reach.html）

- 内嵌 **2026-11-14 从 arXiv Atom API 抓取的真实论文快照**（62 篇 / 276 位去重作者），双击打开即完整可用。
- 点击追踪落在本机浏览器（localStorage）：名片链接 `#/c/<hash>` 每次被打开都会记入漏斗；**跨人的真实追踪仍需 `reach.py` 服务端版**，页面底部有此说明。
- 「我的名片 / 模板」抽屉里可编辑自我介绍与邮件模板（占位符 `{name} {paper} {paper60} {paper80} {link} {profile}`），保存后所有草稿自动重算，配置同样存本机。
- 支持按数据源/数量载入人群、关键词筛选、CSV 导出、一键重置。

## 回应闭环（区别于「点击」）

点击只能证明「有人打开了链接」（注意力，可能误触），**回应才证明「联系上了」**（关系）。所以名片页底部有三个回应按钮：

| 回应 | 系统后续动作 |
|---|---|
| 想聊，约 15 分钟 | 表格置顶；跟进模板自动切换成「直接给时间窗」的约时间版（`followupYes`），不再问一遍要不要 |
| 先不了，改天 | 中等优先级；跟进沿用原来的 `followup` 模板 |
| 不需要，别再来信 | 归档到列表末尾，`sendAll` 直接跳过，跟进按钮消失，不再产生任何消息 |

实现要点：

- 回应**追加式**存储（`state.replies`），最新一条生效；「改主意」= 撤销最后一条，可精确回到上一次选择。
- 可选留一句留言，跟进弹窗里能看到，让第二次沟通有上下文。
- 点回应后的重渲染**不重复计点击**（`showCard(hash, countClick=false)`），点击数和回应数不互相污染。
- 看板新增「回应人数 / 回应率」两个 KPI，漏斗末层多出「回应」；CSV 增加回应、回应时间、留言三列。
- 名片在看板之外的另一标签页打开时，回应通过 `storage` 事件实时同步回看板。

边界：单文件版的回应同样存在本机浏览器（localStorage），所以「回应」只能由同一台机器上的人点出来——它是完整链路的**演示**，不是跨人的真实回执。跨人回执需要服务端承接（`reach.py` 目前还没有 `replies` 表与接口）。

## 怎么改

- **改文案 / 名片 / 邮件模板**：不用改文件，打开 `reach.html` 点右上角「我的名片 / 模板」，改完保存即生效（存本机）。
- **改界面样式或逻辑**：`reach.html` 是自包含的，直接用编辑器改里面的 `<style>` 和 `<script>`；arXiv 数据是文件里 `const SNAPSHOT = [...]` 这一行 JSON 数组，要换数据就替换这段（每项字段：`id / title / authors / published / cat / query`）。
- **需要重新抓一批 arXiv 数据**：跟我要一次即可，我会重新生成快照并替换进 `reach.html`（之前用的抓取脚本已清理，可随时重建）。
